# Admin last visit
The directory records only a single latest server timestamp and coarse OS family per account. On a successful login/confirmation or a real authenticated bootstrap (/api/me or /api/dashboard with the visit header), update the latest row; ordinary API reads, polling and guest requests do not write it. No tracking request, heartbeat, raw User-Agent, IP address or device fingerprint. OS is inferred, not proof of physical device. Legacy users have no historical data. Deploy the additive migration to Staging first; apply to Production only for an approved release. Failed optional writes do not break login. Admin endpoint only, no public table grants.
