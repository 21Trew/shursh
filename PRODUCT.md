# PRODUCT — Шурш! MVP

## Цель

Два сценария в одном продукте: человек собирает подарки и делится списком; компания без путаницы организует Тайного Санту. Интонация дружелюбная, но интерфейс предназначен для взрослых. Продукт не завязан только на Новый год.

## P0, реализованное в локальной версии

- Главная с hero, объяснением сценариев, примером вишлиста, отдельной секцией Санты, объяснением скрытого бронирования и поводами для подарков.
- Регистрация и вход с паролем; демонстрационный аккаунт с образцами; несколько вишлистов.
- Название, описание, повод, четыре оформления, приватность/доступ по ссылке, редактирование/удаление.
- Подарок или впечатление, изображение (JPG/PNG/WEBP до 2 МБ), описание, необязательная цена/валюта/ссылка, приоритет, редактирование/удаление.
- Гостевой просмотр по ссылке без регистрации, атомарная бронь, отмена по личному токену.
- Тайный Санта: создание игры, организатор автоматически становится участником, приглашение, гости без аккаунта, пожелания, удаление участников до жеребьёвки, направленные исключения, жеребьёвка без самоназначений и двойных получателей, фиксация результата, личное раскрытие, заморозка состава.
- Сохранение в SQLite с транзакциями и ограничениями целостности.

## P0, ограничено или отложено

- Нет отправки писем и passwordless; используются локальные пароли.
- Потерянные приватные ссылки гостевого участия или броней не восстанавливаются.
- Максимум 12 участников в одном событии в данной реализации алгоритма.
- Пожелания участников Санты — текстовые, без импорта личного вишлиста.
- Нет пользовательского изображения обложки, есть четыре оформления; у желаний фотографии поддерживаются.
- Локальный встроенный HTTP-сервер, без внешнего деплоя и настройки публичного доступа.

## Сценарии

1. **Владелец:** создать аккаунт → список → желания → скопировать URL.
2. **Гость:** открыть URL → выбрать желание → бронировать → сохранить приватную ссылку → при необходимости отменить.
3. **Организатор:** создать событие → пригласить → настроить направленные исключения → запустить жеребьёвку.
4. **Участник:** присоединиться → сохранить личный URL → записать пожелания → раскрыть назначение после старта.

В UI демоданные и локальное офлайн-превью помечены, не маскируются под реальные совместно используемые данные.
